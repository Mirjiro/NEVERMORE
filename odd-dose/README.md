# ODD DOSE

A cozy discovery, collecting and business game. You run a company that makes mysterious emotion pills: breed new pills in the Lab Machine, copy them in the Vault, ship orders from your Desk, and grow your company at HQ.

```bash
npm install
npm run dev     # play locally
npm test        # engine tests
npm run build   # static site in dist/
```

Progress, architecture and the test checklist live in [BUILD_STATUS.md](BUILD_STATUS.md). All balance numbers are in `src/config/balance.ts`.
